What the checks do

The schema check compares each file's header with its data contract before anything loads; a renamed column stops the whole batch. Duplicates are counted per batch and the newest version of each key is kept. After the merge, unique key and reconciliation checks confirm one row per key and no lost rows. Post-load checks look for orphan references, impossible dates and over-deliveries.

Failed critical checks stop the Airflow run before the dashboard is refreshed.
